# Stardew i18n Translator v1.2.0

This release makes stale translation data easier to spot and local logging easier
to control.

- Scans now list unused target-language keys under **Optional cleanup** without
  affecting progress or blocking export.
- **Settings → About** now includes a switch for local diagnostic logging.
- Logs remain local, rotating, and size-capped; the preference is stored in
  `Data/settings.json`.
