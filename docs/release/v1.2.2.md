# Stardew i18n Translator v1.2.2

This maintenance release simplifies editing and removes an unreliable Nexus
shortcut.

- Added **Open Mods Folder** to the mod-list context menu.
- Translation edits now always use the validated String Editor dialog instead
  of inline table editing.
- The toolbar search appears only while a mod is open.
- Removed **Search Translation on Nexus** because its browser results were not
  reliable.
