Stardew i18n Translator 2.0.0 introduces a redesigned desktop workflow and a
complete optional Codex CLI translation path.

- The new Overview and resizable two-panel Workspace bring scan status,
  multi-component mods, All mods search, filters, multi-select, batch actions,
  and sortable columns into one focused interface.
- Codex CLI can use the installed CLI's existing sign-in, model selection when
  reported, a configurable reasoning level, and best-effort usage status when
  available. Large selections run in bounded, context-aware batches with
  progress, cancellation, optional quality review and repair, and Review-only
  results.
- Complete scans now report changed, added, and removed English strings since
  the previous complete scan and explain exclusions, unused target keys, and
  skipped components more clearly.
- The result tray keeps the five newest session operations, reopens the latest
  result with real paths and copyable details, and provides one safe undo for
  the newest eligible batch edit.
- Local AI now preserves successful suggestions in Review when individual items
  fail. LLM import rejects stale or mismatched batches before applying them, and
  direct export revalidates its scope and rolls back incomplete multi-file
  writes.
