Stardew i18n Translator 2.5.0 brings one Export dialog, plainer texts and token checks that match the game more closely.

- One **Export…** entry asks for This mod or All mods and for ZIP or JSON, and
  says plainly when JSON writes directly into your Mods folder.
- Regional translation files such as `de-DE.json` or `pt-BR.json` are handled
  for every language: read as existing translations and removed on JSON export
  so players see your translation.
- The scan offers only mod folders SMAPI actually loads, and its result explains
  each problem in plain words.
- Token checks catch more real game problems, such as `#$B#` typed instead of
  `#$b#`, and report fewer false ones; every finding says what it does in the
  game.
- Local AI and ChatGPT runs handle refusals, timeouts and unreachable servers
  more calmly, and a single-string translation can be cancelled.
