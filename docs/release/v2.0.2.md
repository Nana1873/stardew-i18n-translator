Stardew i18n Translator 2.0.2 fixes Codex CLI detection after the official
Windows installation.

- Official Codex CLI installations in
  `%LOCALAPPDATA%\Programs\OpenAI\Codex\bin` are now detected even when Windows
  Explorer has not inherited the updated `PATH`.
- Settings no longer reports such installations as **Not installed** with
  authentication **Unavailable**.
- Existing portable, `PATH`-based, and npm Codex CLI installations keep their
  previous lookup priority.
