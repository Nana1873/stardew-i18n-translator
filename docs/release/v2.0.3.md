Stardew i18n Translator 2.0.3 removes noisy validation false positives while
keeping real Stardew control data protected.

- Dialogue text after malformed `#$b$...` and `#$b*...` sequences remains
  translatable instead of becoming one large protected token.
- Valid target-language gender switches and harmless extra spacing in `$r`
  response commands no longer cause token-count errors.
- **Keep original**, localized quote punctuation, and ordinary text reflow no
  longer create distracting validation findings.
- Runtime-sensitive response keys, item-ID pools, `%item money` and
  `%item quest` commands, and `^` line breaks remain protected.
