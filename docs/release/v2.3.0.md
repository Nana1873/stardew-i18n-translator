# Stardew i18n Translator 2.3.0

Stardew i18n Translator 2.3.0 adds parallel ChatGPT batches, clearer workspace activity, and more reliable editing and exports.

- Run ChatGPT batches in parallel with configurable concurrency and progress based on results saved to Review.
- Follow translation stages and operation results in the Activity log, with available model, reasoning, and token details.
- Open directly in the translation workspace after setup; the separate Overview page has been removed. Compact notices, accessible AI progress, and the Issues view keep operation feedback visible.
- Use improved ChatGPT sign-in and retain saved or manually entered models even when the account catalog omits them.
- Save a single space as Done to intentionally suppress text such as an unwanted `Tree` suffix. JSON and translation ZIPs preserve it unchanged; fully empty fields remain Open.
- Share locale-only translation ZIPs with corrected installation paths for Vortex and Mod Organizer 2.
- Preserve unsaved editor work during AI refreshes, keep Undo in its original language, and retain blank-source translations and protected tokens consistently.
