# Stardew i18n Translator 2.3.0

Version 2.3.0 adds parallel ChatGPT batches and fixes editing and export issues.

- ChatGPT can translate several batches at once. You can set how many run in parallel.
- The app opens directly in the workspace; the Overview page has been removed. Activity log shows app actions and AI stages, and Issues lists validation findings.
- ChatGPT sign-in is more reliable. Saved and manually entered models remain available even when missing from the account's model list.
- Save exactly one space to leave a translation blank, for example to remove an unwanted `Tree` suffix. It counts as Done and stays unchanged in JSON and ZIP exports. Empty fields remain Open.
- Fixed incorrect ZIP export paths from the previous release that could break installation in Vortex and Mod Organizer 2.
- Fixed lost unsaved edits, Undo in the wrong language, blank-source exports, and Local AI whitespace and protected-token handling.
