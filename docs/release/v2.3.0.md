# Stardew i18n Translator 2.3.0

Version 2.3.0 adds manual ChatGPT model IDs, parallel translation batches, and a workspace Activity log.

## Added

- **Enter model ID…** in ChatGPT settings lets you type an exact model ID such as
  `gpt-6.1-sol`, including models missing from your account's model list. Manual
  entry also works while the list loads or when discovery fails.
- **Parallel batches** runs ChatGPT batches concurrently, with settings of 1, 2,
  4, 6, or 8 and a default of four. Each batch completes its selected quality
  checks; repeated temporary errors reduce parallelism for the current run.
- **Activity log** records scans, saves, token-mismatch acceptances, batch edits,
  imports, exports, and AI results. AI entries show batch preparation, translation,
  quality review, repairs, retries, saved suggestions, and active steps.
- Expand, collapse, resize, and copy the log. Scrolling up pauses automatic
  following; **Latest entries** returns to the bottom. **Details** reopens
  operation results and the latest scan report. The session log retains up to 500
  entries, protecting up to 100 recent warnings/errors when older entries are removed.
- Edit each component's **Install folder** in selected-mod and all-mod ZIP
  previews. File paths update before export; invalid folders and collisions block
  ZIP creation.
- Save exactly one normal space to intentionally leave a translation blank,
  for example `"Tree": " "` to suppress an unwanted suffix. It becomes Done, looks
  blank in the table, and survives scans, restarts, JSON, and both ZIP exports.
  Clearing it returns a nonblank source to Open; changed English text marks it
  Changed. Protected-token checks still apply.

## Changed

- AI progress stays in a non-modal notice while you work. **Saved to Review**
  counts persisted suggestions, rather than received drafts. Available model,
  reasoning, token usage, and recovery details appear in the completed result.
- The app opens directly in the workspace after setup. The separate Overview
  page has been removed.
- **Issues** lists findings across Open, Changed, Review, and Done while keeping
  your search and mod scope. Yellow warning triangles and red error circles
  explain whether export is allowed. Accepted token mismatches stay visible as
  non-blocking warnings.
- **Files…** replaces **Export…**, separating JSON writes into installed Mods
  folders from translation ZIPs. Compact result notices stack above the Activity
  log, with actions to open affected strings, Review, folders, or full details.
- Row, context, and selection actions use compact menus. Editor copy tools, save
  and approval actions, protected-token hints, and glossary hints have been rearranged.
- ChatGPT settings prefill `gpt-6.1-sol` when no model is saved. The updated app
  icon also appears in About and the browser sign-in confirmation page, which
  directs you to continue in the app for the actual sign-in status.
- ChatGPT draft and quality-review requests now include string keys as context.
  AI instructions allow possessive/contraction apostrophes to follow the target
  language's grammar while preserving enclosing quotation style.

## Fixed

- Fixed incorrect ZIP export paths from the previous release that could break
  installation in Vortex and Mod Organizer 2. Defaults use the component's
  manifest folder without outer staging folders; valid leading spaces are preserved.
- Saved and manually entered ChatGPT models survive model-list refreshes,
  discovery failures/retries, and sign-out. Surrounding spaces in a manual ID no
  longer bypass a known model's supported reasoning levels.
- Background AI refreshes keep unsaved editor text and focus. If the English
  source changes, the draft is preserved and **Use updated source** requires a
  fresh decision before saving, including a new token-mismatch confirmation when needed.
- Delayed saves, approvals, and refresh responses no longer affect a newer
  editor selection. Batch Undo cannot restore translations into another language.
- AI completion and **Open Review** remain tied to the run's original workspace,
  including while other mods load or fail to load. Early cancellation prevents
  startup; a failed cancellation can be retried, and saved suggestions are retained.
- Scans refresh translations and Issues even when filenames are unchanged.
  Export and ZIP problems can open the exact affected string outside the current view.
- JSON, selected-mod ZIPs, and all-mod ZIPs consistently retain translations for
  blank English strings.
- Local AI preserves leading/trailing whitespace and line breaks. Safe
  JSON-string decoding removes accidental encoding without stripping real
  quotation marks or worsening protected-token checks.
- Local AI retries missing, extra, and repeated protected tokens, retaining the
  better token counts. Unresolved differences remain visible in Review.
- Glossary extraction rejects links outside the selected language pack, and
  results from old folder/language settings no longer replace the current status.
- Keyboard navigation includes **Details** headings and skips closed, hidden,
  and disabled dialog controls.
