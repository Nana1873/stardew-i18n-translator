Stardew i18n Translator 2.1.0 adds combined translation output and support for
split locale folders, with more accurate progress and safer background work.

- **Build Stardew Translator Output** collects local translations and saved edits
  from all scanned mods into one ZIP, preserving their installed folder paths.
- Scan, edit and export split locale files such as `i18n/default/Dialogue.json`,
  including translations whose target-language folder does not exist yet.
- Blank source and target pairs no longer count as unfinished work. They reopen
  when a mod supplies text, and obsolete translation keys stay in optional scan
  details.
- Dialogue validation allows more translatable prose while protecting runtime
  lookup keys and other game control data.
- The editor avoids repeated validation and search work. Background loading and
  export preserve newer edits, pending workspace settings and separate ZIP
  results.
