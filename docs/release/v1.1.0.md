# Stardew i18n Translator v1.1.0

This release improves editing speed, export safety, and multilingual handling.

- Added inline editing for short single-line translations.
- Added configurable keyboard shortcuts with conflict detection and reset.
- Added drag-and-drop import for external LLM batch results.
- A protected-token mismatch now blocks the complete mod export before files or
  backups are written.
- Verified Unicode-safe scan, edit, batch, and export workflows across all 11
  advertised target languages.
- Saved translation work is now isolated by language under
  `Data/language-state/<code>/translations/`.

## Upgrade

Keep the existing `Data/` folder. Earlier state under `Data/translations/` is
migrated once into the language selected during the upgrade.
