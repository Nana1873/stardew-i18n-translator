# Stardew i18n Translator v1.2.1

A small correctness patch for export and saved translation state.

- Clearing every translation now removes the stale `i18n/<lang>.json` after
  creating a backup, allowing SMAPI to fall back to English.
- Duplicate mod `UniqueID` values now produce a scan warning instead of sharing
  one saved-state file.
- Imported community translations now receive a source baseline and can be
  marked **outdated** after the mod's English text changes.
