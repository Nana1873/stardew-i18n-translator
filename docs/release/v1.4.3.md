Stardew i18n Translator 1.4.3 adds an explicit escape hatch for intentional token mismatches.

- Saving a string with protected-token errors now asks whether to go back or save it anyway.
- Each accepted mismatch is remembered independently, so multiple confirmed strings can be exported together.
- Editing the translation or receiving an updated English source requires the mismatch to be confirmed again.
- Unaccepted token errors remain blocking for direct exports and translation-package ZIPs.
