Stardew i18n Translator 2.0.1 fixes protected-token detection for real mod
strings.

- Bracketed UI labels and status messages such as `[Right]` and `[LEFT]` can
  now be translated instead of being blocked as runtime tokens.
- Gendered dialogue branch text inside `${...}$` is now translated while the
  switch structure and nested Stardew tokens remain protected.
- Structural switch mismatches are explained without offering invalid literal
  placeholders for insertion.
