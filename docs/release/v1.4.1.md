# Stardew i18n Translator v1.4.1

Custom-language support and glossary building are broader and easier to use.

- Added Vietnamese (`vi`), Indonesian (`id`), Ukrainian (`uk`), Polish (`pl`),
  Finnish (`fi`), Dutch (`nl`), and Czech (`cs`) as curated targets.
- Built-in languages can now build a glossary directly from local
  `Content/Strings/*.xnb`; unpacked JSON remains available as a fallback.
- Community language packs can provide glossary terms from either JSON or XNB
  string dictionaries.
- Setup can build the glossary automatically when a usable local source is
  available.
- Publishing a GitHub release now uploads the same portable ZIP to Nexus Mods.

## Upgrade

Keep the existing `data/` folder. Rebuild the glossary after updating Stardew
Valley or an installed language pack. Custom-language targets still require a
matching in-game language mod.
