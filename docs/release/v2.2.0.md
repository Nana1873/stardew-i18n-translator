# Stardew i18n Translator 2.2.0

Stardew i18n Translator 2.2.0 adds direct ChatGPT sign-in and a more compact translation workspace.

- Sign in with ChatGPT inside the app, choose an account model and reasoning level, and manage usage without installing a CLI.
- Keep source and translation columns readable in narrow windows, reset column widths with Fit columns, and use simpler settings, progress and export previews.
- Start scanning automatically after setup and retry exports through a fresh validation preview and confirmation.
- Preserve the original tone and character voice across AI languages, and retain valid drafts with a visible warning when quality review fails.
- Protect portable work against simultaneous app instances and show recovery or sign-out problems clearly.
- Remove the Translation Notes menu and generated publication text.

## Upgrade

Keep the existing data/ folder beside the executable. If you used Codex CLI translation, sign in again through Settings > Translation engines > ChatGPT; the old CLI session is not imported.
