# Stardew i18n Translator v1.4.2

This patch makes translation files, local AI, external batches, and keyboard
workflows safer without changing the app's lightweight local-first design.

- Translation sources are validated before export, with safe backups, atomic
  per-file replacement, clearer partial Export All results, and canonical
  Portuguese `pt.json` handling.
- Language, local-AI URL/response, state-file, JSON, and XNB boundaries now fail
  safely on invalid, ambiguous, incomplete, or oversized input.
- External LLM batch format 2 uses one compact source snapshot, validates the
  mod/language/files/keys/source before import, preserves local translations,
  and stages accepted values as **Needs review**.
- Failed or delayed settings/editor saves no longer move the UI early, and stale
  AI/model responses cannot overwrite newer work.
- Settings, mod rows, and string rows are fully keyboard navigable; CSS semantic
  colors are now statically checked.

## Upgrade

Vor dem Update offene LLM-Batches aus v1.4.1 oder älter noch mit der bisherigen
Programmversion importieren und prüfen. v1.4.2 akzeptiert nur neu erzeugte
Batchdateien im Format 2.
