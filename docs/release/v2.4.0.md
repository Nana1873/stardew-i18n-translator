Stardew i18n Translator 2.4.0 stops a few token problems from blocking whole mods.

- Token checks now tell real errors that would break the game apart from
  harmless differences. Changed portraits, a removed he/she variant, or a
  missing player name `@` are only notes and never block.
- Export and translation ZIPs leave out only strings with real errors; the game
  shows their English text and everything else is written.
- LLM batch imports never block on tokens. Every value goes to Review with its
  findings listed.
- Findings are explained in plain language, for example a he/she switch missing
  its closing `}$`, including full-width look-alikes such as `＄｛｝＾`.
- Local AI and ChatGPT no longer spend extra requests on harmless differences.
