Stardew i18n Translator 2.3.1 makes LLM batch imports less all-or-nothing.

- A few strings with protected-token issues no longer block the whole batch.
  After an explicit opt-in, they are imported to Review with the rest. Export of
  that mod stays blocked until they are fixed or accepted in the editor.
- Token issues in the import dialog are now explained in plain language, for
  example a gender switch `${...^...}$` missing its closing `}$`, and show the
  imported text.
- Full-width look-alikes such as `＄｛｝＾`, which some LLMs write instead of
  `$ { } ^`, are pointed out.
