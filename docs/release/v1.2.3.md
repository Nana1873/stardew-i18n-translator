# Stardew i18n Translator v1.2.3

This patch improves settings safety and restores a few inconsistent workflows.

- Settings are written atomically and recover from the last valid
  `Data/settings.json.bak` when possible.
- Quote-delimiter differences now produce a review warning instead of blocking
  export or triggering a local-AI retry.
- **Mark as translated** no longer gives empty rows a translated status.
- Global search once again finds keys, source text, and translations across all
  scanned mods.

## Upgrade

Keep the existing `Data/` folder. The settings backup is created automatically
after a later successful settings write.
