# Stardew i18n Translator v1.3.0

This release makes translation packages easier to prepare and share.

- Export, import, batch, and release-ZIP results now stay in a persistent result
  tray without blocking the workspace.
- **Build Release ZIP** creates an installable archive while preserving the mod
  package's folder structure.
- **Translation Notes** creates short publication text from the current package,
  language, coverage, and review state.
- External-LLM batches include a complete handoff and copyable prompt.
- The launcher now explains how to install Microsoft WebView2 when it is missing.

## Upgrade

Keep the existing `Data/` folder. No data migration is required.
