# Stardew i18n Translator v1.4.0

Custom-language targets and glossary data now stay properly isolated by
language.

- Added Thai (`th`) as the first curated custom-language target.
- Custom-language targets work with editing, export, local AI, and external LLM
  batches even when Stardew has no official locale for them.
- Glossary caches now live per language under
  `data/glossary/glossary-<lang>.json`.
- Glossary hints now use typed, high-confidence terms instead of a broad
  untyped name map.
- Installed community language packs are excluded from the normal mod list and
  may provide glossary terms for custom languages.

## Upgrade

Keep the existing `data/` or `Data/` folder and rebuild the glossary. Custom
languages may have no glossary hints when no compatible language pack is
installed.
